# Ночной прилавок

Казуальная ночная аркада на Godot 4. Одна ночь, пять разных мест и три героя. Интерфейс на русском.

Скачай архив, открой проект в Godot и нажми Play. Отдельной сборки нет: так игра запускается на Linux, Windows и macOS.

## Как поиграть

1. Скачай [Godot 4.7](https://godotengine.org/download) или новее. Нужен обычный редактор, не .NET-версия. Шаблоны экспорта не нужны.
2. На странице репозитория нажми **Code → Download ZIP** и распакуй архив.
3. В Godot выбери **Import**, укажи файл `project.godot` из распакованной папки и подтверди импорт.
4. Нажми **F5** (или кнопку Play).

Если Godot уже стоит и команда `godot` есть в терминале:

```sh
godot --path .
```

На Linux, если окно не появилось, запусти так:

```sh
godot --path . --display-driver x11
```

## Управление

- **1, 2, 3** — выбрать героя
- **WASD** или стрелки — ходить
- **Пробел** — рывок. В конторе пробел берёт мешок и сдаёт счёт
- **Мышь** — необязательна. Герои сами бьют ближайшего. Отведи курсор подальше, если хочешь указать цель сам
- **Esc** — пауза. Из паузы и из окна прокачки можно вернуться в меню

## Пять мест одной ночи

Прокачка сохраняется между местами. Смерть возвращает только на текущее место, с уже взятыми улучшениями.

1. **Площадь.** Отбей 14 мотыльков и карманников.
2. **Причал.** Донеси три ящика к прилавку. Угри бьют, если пересечь их след. С ящиком бежишь медленнее и без рывка.
3. **Контора.** Три раза собери на мешках ровно сумму долга. Меньше или больше — не считается.
4. **Переулок.** Зажги четыре фонаря на ходу. Тени бросаются, только если остановиться.
5. **Рассвет.** Свали Ночного сборщика. Он метит рывком, потом зовёт мотыльков.

## Что не лежит в репозитории

Сам редактор Godot сюда не входит: он весит больше игры и ставится с сайта. Папка `.godot/` создаётся локально при первом открытии проекта.
